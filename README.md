# Study Journal

사진으로 저장한 학습 자료를 Google Vision 문서 OCR로 읽고, 키워드로 검색하는 React/FastAPI 웹앱입니다.

기능: 회원가입과 로그인, 이미지 업로드, OCR 문장 추출, 관련 문장 검색과 강조, 원본 이미지 확대, 갤러리 조회 및 삭제.

배포 방법은 DEPLOY.md를 참고하세요. Google Vision API 키는 배포 서버의 환경변수로 설정합니다. 저장소에는 넣지 않습니다.

기술: React, TypeScript, Vite, Tailwind CSS, FastAPI, SQLite, SQLAlchemy, Google Cloud Vision.
